# 都市計畫委員會會議紀錄資料庫

Urbancode Commission 是 g0v 開放都市計畫專案的一部分，整理並提供都市
計畫委員會會議紀錄的瀏覽與搜尋介面。

網站：<https://commission.urbancode.tw/>

## 功能

- 依行政區瀏覽已收錄的會議紀錄
- 查看會議案件與相關內容
- 搜尋會議紀錄
- 在資料可用時連結至官方文件
